网页保存与整理 1.1.0

1. 将“网页保存与整理.app”拖入“Applications（应用程序）”，然后双击启动。
2. 安装包自带运行库，不需要安装 Python、打开终端或填写 API Key。
3. 网页功能需要 Google Chrome；本地 TXT 整理可以离线使用。
4. 粘贴网址 → 收集章节链接 → 后台保存网页 → 确认书名及输出目录 → 导出 TXT。
5. 输出目录仅生成“书名.txt”。导出成功后可选择“清理本次网页”，将本次使用的网页移到废纸篓。
6. 新任务的网页分别放在应用数据目录；不会自动删除旧版网页。
7. 只有主动点击“网页登录”才显示 Chrome。日常收集与保存默认后台进行。

universal2 架构（arm64 + x86_64），最低系统声明 macOS 11；Intel 实机及各旧版系统尚未验证。
